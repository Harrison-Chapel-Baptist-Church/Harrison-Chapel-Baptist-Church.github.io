How to install

  1. Download the official APK using the link above once available.
  2. Open the downloaded file on your Android device.
  3. If prompted, temporarily allow installation from your browser or file manager.
  4. Install and open Harrison Chapel, then sign in with your existing account.
  5. Turn off the temporary installation permission afterward.

Only install APKs from this official church website. Android may warn about apps installed outside Google Play.
